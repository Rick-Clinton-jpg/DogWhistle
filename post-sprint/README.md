# Post-sprint evidence

These November 2026 analyses follow the October sprint. The five entries include two unsuccessful runs and an exploratory analysis of saved decisions.

| Entry | Result |
|---|---|
| [DogWhistle in the PoPLi setting](popli-archive/README.md) | DogWhistle’s adapted score agreed with the published result for both outsider comparisons. |
| [Active-listener pilot with Luna](active-listener-luna/README.md) | DogWhistle flagged 6/12 informed cases and 0/12 no-code cases. The pilot fell short of its criteria. |
| [Worked-example gate with Luna](worked-example-gate/README.md) | The informed listener followed the code on 26/48 decisions (54.2%). The run stopped after four requests. |
| [Exploratory association](association/README.md) | Code-following and score were positively associated when calculated from the same choices. The association was weak on disjoint choices. |
| [Matched rerun with Sol](matched-sol/README.md) | On the original pilot packets, DogWhistle flagged 12/12 informed cases and 0/12 no-code cases. |
